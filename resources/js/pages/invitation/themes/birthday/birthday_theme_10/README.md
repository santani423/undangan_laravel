# Dunia Mainan 3D — undangan ulang tahun anak

- Entri: `BirthdayTheme10.tsx` (terdaftar di `pages/invitation/show.tsx` sebagai `birthday_theme_10`). Gaya: `birthday-theme-10.css` (semua kelas `bt10-`, token warna & font di `.bt10`).
- Konsep: satu pulau mainan real-time (three.js + React Three Fiber). Menggulir halaman menerbangkan kamera melewati lima tujuan — gerbang, panggung balok (profil), taman pesta + kue raksasa (acara), korsel foto (galeri), plaza kado (RSVP, kado digital, terima kasih). Kartu HTML tampil di sisi yang tidak menutupi objek 3D-nya; di ponsel kartu berada di bawah.
- Data undangan dipetakan di `lib/data.ts` (`buildInvitation`); teks khas tema ada di `TEKS`. Fitur yang dimatikan di pengaturan undangan (`features`) menyembunyikan section-nya dan kamera terbang melewati tempat itu (`lib/journey.ts`).
- Simulasi tanpa backend: `<BirthdayTheme10 invitation={MOCK_INVITATION} />` dari `lib/mock.ts`. Tanpa `rsvpEndpoint`/`wishesEndpoint`, RSVP & ucapan memakai penyimpanan demo di peramban (`services/rsvpService.ts`) dan formulir menyatakannya dengan jelas. Undangan contoh tanpa foto memakai ilustrasi galeri berlabel "Foto contoh".
- Struktur: `sections/` (cover, profil, acara, galeri + lightbox, RSVP/ucapan, kado, terima kasih), `components/` (kartu mainan, ikon paket aset, toast, top bar, layar muat, dunia 2D cadangan), `store/` (state bersama HTML ↔ 3D, nilai perjalanan kamera, event konfeti), `hooks/` (scroll ↔ kamera via GSAP ScrollTrigger, hitung mundur, musik, swipe), `audio/` (lagu undangan atau kotak musik yang disintesis), `scene/` (dunia 3D, dimuat malas di chunk sendiri), `assets/` (paket aset asli: ilustrasi, tekstur rumput, sprite, ikon UI).
- RSVP ke API undangan: `POST {rsvpEndpoint}` `{ name, number_of_guests (tamu + pendamping), rsvp_status: attending|not_attending|maybe, message, guest_slug }`; dinding ucapan membaca `GET {wishesEndpoint}?page=`. Bila RSVP dimatikan tetapi ucapan aktif, formulir menjadi formulir ucapan (`POST {wishesEndpoint}`).
- Musik: lagu undangan bila ada (mengikuti autoplay/loop); tanpa lagu, melodi kotak musik orisinal disintesis di peramban dan mulai saat "Buka Undangan" ditekan.
- Penyesuaian dari desain asli: tanpa dependensi baru (drei `PerformanceMonitor`/`useProgress` → `PerformanceWatch` di `scene/ToyWorldCanvas.tsx` + `scene/core/loading.ts`; Tailwind → CSS biasa; Fontsource → Google Fonts), "hal kesukaan" diganti "Cerita kecil" dari `lifeJourney`, QRIS dompet digital, umur kosong menampilkan ★.
- Tanpa WebGL, saat renderer gagal, atau bila chunk 3D gagal dimuat, tampil dunia mainan 2D dari ilustrasi paket aset dengan isi undangan tetap lengkap.
- Parameter URL: `?to=Nama+Tamu`, `?quality=high|medium|low`, `?webgl=off` (atau `?nowebgl=1`), `?motion=reduce`. Di `npm run dev`, `window.__toyJourney` & `window.__toyGL` tersedia untuk uji otomatis.
- Proyek Vite asli (sumber desain + build `dist/`) dipindah ke `resources/views/themes/birthdayThemes/birthday_theme_10/` agar tidak ikut dikompilasi glob halaman Inertia.
