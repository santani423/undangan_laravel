# 3D model checklist

This starter pack does not contain production GLB/GLTF meshes. Add optimized models here:

- `dr-smiley.glb` — hero mascot, ideally with idle/wave/jump/celebrate animations
- `main-gate.glb` — entrance gate
- `dental-clinic.glb` — cute clinic building
- `birthday-party.glb` — party environment
- `playground.glb` — activity scene
- `candy-land.glb` — connecting path and props
- `birthday-cake.glb`, `gift-box.glb`, `balloon-cluster.glb`
- `photo-frames.glb`, `rsvp-board.glb`

Recommended sources: original Blender models created for this project or assets with licenses that permit commercial use. Verify attribution, redistribution, and modification terms before shipping.
Optimize for mobile; use GLB + Draco or Meshopt compression where your pipeline supports it.
